# MOOBUN Web

Modern responsive React + TypeScript + Vite storefront for MOOBUN.

## Run
npm install
npm run dev

## Production
npm run build
npm run preview

## Configure
- WhatsApp number: `src/main.tsx` constant `WA`
- Product catalog/prices: `products`
- Delivery-app URLs: section `Available on Delivery Apps`
- Product image URLs can be replaced with the final MOOBUN product photography.
